Wikipedia Full-Text Search with BM25 and Inverted Files

by: Eric S. Téllez

This demonstration illustrates high-performance full-text search using BM25 Inverted Files with TextSearch.jl and SimilaritySearch.jl.

Unlike a conventional inverted index that computes term statistics locally on the loaded documents, BM25InvertedFile can leverage a pre-trained TextProfile (trained over 14.5 million paragraphs of Spanish Wikipedia) to borrow corpus-wide Inverse Document Frequencies (IDF) and average document lengths.

using SimilaritySearch
using TextSearch
using JSON3
using Markdown
using Printf

Loading the Wikipedia Profile and Corpus

We load the pre-trained Spanish Wikipedia profile and a sample collection of 60,000 paragraphs from the JSONL corpus.

# 1. Load the pre-trained profile containing global vocabulary and IDF statistics
profile_path = joinpath(@__DIR__, "..", "..", "TextSearch.jl", "corpus-profiles", "profiles", "wiki20231101-es-paragraphs.zip")
profile = load_profile(profile_path)
@info "Profile loaded:" vocsize=vocsize(profile.model.voc) trainsize=profile.model.voc.trainsize[]

# 2. Load paragraphs from the JSONL corpus
corpus_path = joinpath(@__DIR__, "..", "..", "TextSearch.jl", "corpus-profiles", "work", "wikipedia", "wiki20231101-es-paragraphs.jsonl")

const MAX_DOCS = 60_000
texts  = String[]
titles = String[]
urls   = String[]

open(corpus_path) do f
    for (i, line) in enumerate(eachline(f))
        i > MAX_DOCS && break
        isempty(strip(line)) && continue
        obj = JSON3.read(line)
        push!(texts, String(obj.text))
        push!(titles, String(obj.title))
        push!(urls, String(obj.url))
    end
end

@info "Loaded paragraphs: $(length(texts))"

Building the BM25 Index

We construct the BM25InvertedFile using the loaded profile. We enable query expansion (expansion=true) to widen queries with the profile’s semantic expansion network.

idx = BM25InvertedFile(profile; expansion=true)
ctx = InvertedFileContext()

# Parallel in-memory indexing
@time append_items!(idx, ctx, texts)
@info "Indexed documents in BM25: $(length(idx))"

Search and Display Helpers

We define a helper function to execute queries and format the retrieved documents:

function search_wikipedia(invfile, ctx, qtext::String, k::Int=5; t::Int=1, policy::QueryPolicy=invfile.query.policy)
    res = knnqueue(KnnSorted, k)
    t_search = @elapsed search(invfile, ctx, qtext, res; t, policy)

    md = [
        "### Query: _«$qtext»_",
        "Search time: **$(@sprintf "%.2f ms" (t_search * 1000))**",
        "",
        "| # | Article Title | BM25 Score | Snippet |",
        "|---|---------------|------------|---------|"
    ]

    for (j, p) in enumerate(IdDistView(res))
        doc_id = p.id
        score  = -p.dist   # BM25 stores negated scores internally
        tit    = titles[doc_id]
        url    = urls[doc_id]
        txt    = replace(texts[doc_id], "\n" => " ")
        snippet = length(txt) > 140 ? first(txt, 140) * "..." : txt

        push!(md, "| $j | [**$tit**]($url) | $(@sprintf "%.2f" score) | $snippet |")
    end

    Markdown.parse(join(md, "\n"))
end

Literal Search vs. Query Expansion

The query expansion network derived from LSI enables matching documents even when the query uses synonyms or related terms not literally present in the document.

We can adjust query behavior via QueryPolicy(expansion=...):

query = "astronomía planetas celestes"

display(Markdown.parse("#### With Semantic Expansion (`expansion=true`):"))
search_wikipedia(idx, ctx, query, 4; policy=QueryPolicy(expansion=true)) |> display

display(Markdown.parse("#### Literal Search (`expansion=false`):"))
search_wikipedia(idx, ctx, query, 4; policy=QueryPolicy(expansion=false)) |> display

Search Throughput

We evaluate batch query throughput in queries per second (QPS):

test_queries = [
    "inteligencia artificial", "mecánica cuántica", "arquitectura gótica",
    "filosofía presocrática", "teorema de pitágoras", "cambio climático",
    "sistema nervioso central", "economía de mercado", "energía nuclear",
    "pintura renacentista"
]

res = knnqueue(KnnSorted, 5)
t_total = @elapsed begin
    for q in test_queries
        reuse!(res, 5)
        search(idx, ctx, q, res)
    end
end

qps = length(test_queries) / t_total
Markdown.parse("""
**Throughput:** $(@sprintf "%.1f" qps) queries per second on an index of $(length(idx)) documents.
""")

Throughput: 161.2 queries per second on an index of 60000 documents.
